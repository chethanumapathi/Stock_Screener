Custom Python Stock Screener Guide

1. Structure of a Screen Script

Every script must define a function named screen(df) which is run against each stock's historical data.

Input DataFrame (df) Columns:
  • Date: String (YYYY-MM-DD), sorted chronologically (ascending).
  • Open, High, Low, Close, Prev_Close, Volume: Float64 (fully adjusted for splits).

2. Return Types

To backtest your script historically and draw the bar chart, return a Dictionary of Series:

return {
    "signal": df['Close'] > df['EMA50'], # Boolean Series representing condition over time
    "EMA50": df['EMA50'] # (Optional) Custom column values to display in results table
}

4. Strategy Template: RSI Oversold Reversal

def screen(df):
    # Calculate 14 RSI
    delta = df['Close'].diff()
    gain = (delta.where(delta > 0, 0)).rolling(window=14).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(window=14).mean()
    rs = gain / (loss + 1e-9)
    df['RSI'] = 100 - (100 / (1 + rs))
    
    # Signal: RSI crosses above 30
    prev_rsi = df['RSI'].shift(1)
    signal = (prev_rsi <= 30) & (df['RSI'] > 30)
    
    return {
        "signal": signal,
        "RSI": df['RSI'].round(1)
    }
